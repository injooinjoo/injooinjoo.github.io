From chatting with AI to delegating and reviewing workAI와 대화하는 앱에서, 일을 맡기고 확인하는 앱으로

Sidekick · 사이드킥 · APP · Published작성·공개 2026-10-21

A mobile app that turns content goals into recurring work for an AI team and reviewable results, for people without time to manage YouTube or blogs every day.유튜브·블로그 운영에 매일 시간을 쓰기 어려운 사용자를 위해, 목표를 AI 직원 팀의 반복 업무와 검토 가능한 결과로 연결하는 모바일 앱.

The starting problem출발한 문제

Content operations involve persistent planning, production, revision, and publishing rather than a single answer. The app addresses work that can continue without constant attention while bringing users back for decisions.콘텐츠 운영에는 한 번의 답변보다 기획·제작·수정·발행으로 이어지는 지속적인 일이 많습니다. 사용자가 매 단계마다 붙어 있지 않아도 업무가 이어지고, 결정이 필요한 순간에는 돌아와 확인할 수 있는 구조를 다룹니다.

Design choices중요한 설계 판단

Goal-setting conversations connect to AI teams and recurring routines, with progress and outputs represented as reviewable cards. Approval for external actions and user/project execution boundaries matter more as conversation becomes real work.목표를 묻는 대화를 AI 직원 팀과 반복 루틴으로 연결하고, 진행과 결과를 검토 가능한 카드로 표현했습니다. 외부 행동의 승인과 사용자·프로젝트별 실행 공간을 별도 경계로 다루는 이유는, 대화가 실제 작업으로 이어질수록 권한과 상태의 의미가 커지기 때문입니다.

What is implemented구현한 경험

  • A conversation about goals and topics leads into team setup, task execution, and result cards. Users answer follow-up questions and review outputs in chat.목표와 주제를 묻는 대화에서 팀 구성·업무 실행·결과 카드로 이어지도록 설계했습니다. 사용자는 채팅에서 필요한 질문에 답하고 결과를 검토합니다.
  • State flows track recurring work, interruptions, resumption, and approval requests. External actions such as publishing and sending connect to user review and approval.반복 루틴의 진행·중단·재개와 승인 요청을 상태로 관리합니다. 발행·전송 등 외부 작업은 사용자가 결과를 확인하고 승인하는 흐름에 연결했습니다.
  • The mobile UI is separated from execution, permissions, and usage accounting. Data and AI execution spaces are scoped by user and project, with a Cloud Run control plane and GKE dedicated-runtime configuration.모바일 UI와 실행·권한·사용량 관리를 분리하고, 사용자·프로젝트별 자료와 AI 실행 공간을 구분했습니다. Cloud Run 운영 계층과 GKE 전용 런타임 구성을 관리합니다.

React Native / Expo · JavaScript · Python / FastAPI · Supabase · PostgreSQL · Cloud Run · GKE / Hermes
